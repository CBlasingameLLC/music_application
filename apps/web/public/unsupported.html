Étude needs a newer web engine

This device's web engine is too old to draw Étude. Rather than show a broken page, Étude is stopping here.

Checking the engine…

The engine is not part of Étude; it belongs to the device:

  • In the Android app it is Android System WebView — on Fire tablets, Amazon WebView. It is updated with the device's software, so install the latest system update, and check for updates in the app store the device uses.
  • In a browser it is the browser itself. Update it, or use a current Chrome, Edge or Safari.

If you think this device is fine — the check can be wrong — you can try the app anyway.
